# Studio DinerPass editor
Strumenti → DinerPass → Carica catalogo → Nuova edizione. Upload JPG/PNG/WebP fino a 12 MB, ricodifica client JPEG 1000×606, massimo 150 kB, firma e dimensioni file verificate sul server. JPEG visualizzato come immagine, nessun SVG o HTML caricato. Database privato, operatori verificati tramite tabella Studio, audit delle modifiche. Pubblicare solo traguardi gratuiti; soglie e tipologia immutabili dopo pubblicazione, grafica e nome modificabili. Paid editions: prezzo 0,99–99,99 EUR, solo bozze, nessuna pubblicazione/checkout o assegnazione di diritti a pagamento. Limite 100 edizioni; non è un editor vettoriale o un sistema di vendita. Nessuna modifica alla reputazione o ai QR.
