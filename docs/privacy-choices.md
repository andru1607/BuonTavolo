# Registration choices — pilot only
Separate required pilot terms and preliminary privacy acknowledgement, optional unselected sharing preference. Server records version, timestamp and event history at signup; prior accounts and cached clients are not presumed to have accepted. Profile provides read and update/withdrawal. No real disclosure is permitted by a pilot preference. A separately approved final notice and fresh consent workflow are required before enabling sharing. The final notice/version must be implemented and verified; gate remains disabled. No retroactive consent. Database fixtures that temporarily enable the gate must explicitly supply a synthetic approved_notice_version.
